# Worksheet Asset Library

All Twinkl worksheets and printable resources. Files in session folders (`sessions/YYYY-MM-DD/assets/`) are copies of what was actually used on that date.

| File | Description | Best used for |
|------|-------------|--------------|
| `InitialSounds.pdf` | Circle the letter a word begins with | Warm-up / initial-sound awareness. Not a blending exercise. |
| `MatchWordsPictures.pdf` | CVC word booklet — match word to picture, read and draw | Phase 1 and 2 core activity |
| `WordLadders.pdf` | Rhyming families: -at, -an, -et, -en, -it, -in, -ot, -op, -ug | Blending practice — use one family per session |
| `RhymingOddOneOut.pdf` | Rhyme discrimination strips | Phase 2 onward |
| `WordFormation.pdf` | Build words from onset + rime (-all, -ip, -it, -ot, -ed) | Phase 2 (-ed family) and Phase 3 (-ip, -it families) |
